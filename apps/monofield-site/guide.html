USER GUIDE · 0.11.7-preview.8

하고 싶은 일에서누를 곳을 바로 찾는 사용 가이드

MonoField는 이미 쓰는 Codex나 Claude Code를 내 PC에서 실행해, 코드에서 SI 산출물(인터페이스 명세서, 화면명세서)을 만들고 코드가 바뀔 때 산출물도 맞춰 주는 작업 도구입니다. 이 문서는 하고 싶은 일에서 누를 곳을 바로 찾는 사용 가이드입니다. 처음이라면 처음 시작하기(15분)를 먼저 따라 해 보세요. 예제 프로젝트로 명세서를 만들고 바꾸는 데까지 갑니다.

이 가이드의 본문은 한국어입니다. 화면 이름은 앱의 한국어 표시를 따릅니다.

바뀐 API가 호출하는 쪽을 깨는지 보기제안 화면 위쪽 호출자 호환성 (호환성 깨짐 · 확인 필요 · 추가 변경)문서 변경 검토

팀 용어 사전 재사용하기설정 → 사전함처음 시작하기 5장

02

설정 한눈에

설정(톱니바퀴)을 누르면 열립니다.

설정 항목무엇을 하나요
실행 모드Codex·Claude Code 같은 로컬 CLI로 일할지, API 키(BYOK)로 일할지 고릅니다. 명세서 흐름은 로컬 CLI가 필요합니다.
실행 권한읽기 전용 · 기본 · 전체 접근 중 하나를 고릅니다(샌드박스·관리자 권한).
외부 MCP외부 서비스의 MCP 도구를 더하고, 맨 위의 REA 설치·연결 점검에서 내장 REA를 점검하고 켜고 끕니다.
사전함여러 프로젝트에서 재사용할 용어 사전을 관리합니다.
데이터베이스 연결프로젝트에 쓰는 DB 연결을 관리합니다.
프로젝트 위치워크스페이스를 저장할 기본 폴더를 정합니다.
스킬에이전트가 작업 중 호출할 수 있는 기능 스킬을 봅니다. legacy-system-handover도 여기서 확인합니다.
메모리대화에서 자동으로 추출된 개인 정보와 업무 프로필을 보고 지웁니다.
지침 / 규칙모든 대화에 고정해서 적용할 어시스턴트 규칙을 적습니다.
언어 · 화면 모드 · 알림 · 개인정보 보호인터페이스 언어(이 브라우저에 저장), 화면 모드, 알림, 개인정보 설정입니다.

03

레퍼런스 보드

  1. 작업공간의 + (새 탭) → 새 브라우저를 엽니다.
  2. 참고할 사이트를 열고 주소창 오른쪽 레퍼런스로 담기를 누릅니다. 메모(무엇이 좋았는지)와 가져올 것(화면 구조·흐름·필드 구성·상호작용)을 고르고 담기를 누릅니다.
  3. 새 브라우저 탭의 시작 화면 맨 위 담은 레퍼런스에 카드로 쌓입니다. 하나 이상 체크하고 선택한 n개 프로젝트에 넣기를 누릅니다.
  4. 넣을 위치(파일 경로나 화면 이름)와 요청을 적고 입력창에 넣기를 누르면 채팅 입력창에 부탁문이 붙습니다. 확인하고 보내세요.
  5. 흐름이 중요하면 카드의 REA로 흐름 기록을 씁니다. 단계(버튼 누르기·입력·기다리기)를 적으면 내장 REA가 새 임시 브라우저 프로필로 실행하고 호출한 API와 마지막 화면을 카드에 붙입니다.
  6. 화면을 만든 뒤에는 우리 화면과 비교를 눌러 우리 앱 주소를 넣습니다. 같은 단계로 우리 화면을 기록해 단계마다 나란히 비교하고, 다른 단계는 차이를 입력창에 넣기로 AI에게 고쳐 달라고 합니다.

지키는 것

  • 패턴만 가져옵니다. 문구·이미지·로고·브랜드 색·글꼴은 복사하지 않고, 이 프로젝트의 코드·컴포넌트·스타일로 다시 만듭니다.
  • 로그인이나 봇 차단을 대신 통과하지 않습니다. 새 임시 프로필로 열기 때문에 로그인한 화면의 흐름은 기록되지 않습니다.
  • 비밀번호·인증번호·카드번호 칸에는 입력 단계를 만들 수 없고, 주문·결제·전송 버튼은 단계에 넣지 마세요. 입력하는 값은 공개해도 되는 값만 쓰세요(증거 파일에 남습니다).
  • 파일은 프로젝트의 references/ 폴더에 쌓이고, 이 폴더의 .gitignore가 코드 저장소 변경에 섞이지 않게 합니다.
monofield refs list    --project <id>
monofield refs add     --project <id> --url https://example.com/join --note "2단계 가입" --take flow,fields
monofield refs apply   --project <id> --id <ref-id> --target src/pages/Join.tsx --request "가입을 두 단계로"
monofield refs record  --project <id> --id <ref-id> --click 다음
monofield refs compare --project <id> --id <ref-id> --url http://localhost:8080/join

04

REA는 MonoField에 들어 있습니다

  • REA(rea-agents 6.7.0)는 MonoField에 들어 있습니다. Node.js 설치나 npx 내려받기가 필요 없습니다.
  • 대화에서 AI가 REA 쓰기는 기본으로 켜져 있습니다. Claude Code, Codex, OpenCode와 지원 ACP 에이전트가 별도 설정 없이 REA 도구를 받습니다. 새 대화부터 적용됩니다.
  • 끄거나 다시 켜려면 설정 → 외부 MCP 맨 위의 REA 설치·연결 점검에서 스위치를 누르거나, 명령줄에서 monofield rea disable / monofield rea enable을 씁니다. 상태는 monofield rea status로 봅니다.
  • 브라우저 기록에는 PC에 설치된 Chrome·Edge·Chromium이 필요합니다. 실행 파일 분석에 쓰는 Ghidra·Java 폴더는 REA 설치·연결 점검에서 한 번 지정합니다(선택).
  • BYOK(API 키)만 연결한 대화에는 REA 같은 도구가 주어지지 않습니다. 로컬 CLI 에이전트를 쓰세요.

05

실행 권한

단계하는 일언제 쓰나요
읽기 전용파일을 읽고 계획만 세웁니다. 아무것도 바꾸지 않습니다.처음 보는 코드에 질문만 할 때
기본 (권장)작업 폴더 안에서만 파일을 고치고 명령을 실행합니다.명세서 생성, 코드 수정 등 거의 모든 작업
전체 접근PC 전체에서 확인 없이 실행하고, Windows에서는 관리자 권한으로 다시 시작합니다.빌드 도구가 관리자 권한을 요구할 때만

명세서를 만들면 프로젝트 안에 파일이 생기므로 읽기 전용에서는 만들 수 없습니다. 바꾼 단계는 그 뒤에 시작하는 작업부터 적용됩니다.

06

알아 둘 것

  • 코드가 외부로 나갑니다. Codex·Claude Code가 코드를 읽고 해당 AI 회사의 모델을 호출하므로 코드 일부가 그 회사로 전송되고 요금도 그 계정 기준으로 나갑니다. 회사·고객사 코드라면 외부 AI 사용이 허용되는지 먼저 확인하세요.
  • 설치본은 아직 코드 서명이 없습니다. Windows의 "PC 보호" 창이 뜨면 추가 정보 → 실행을 누르고, 필요하면 릴리스의 SHA256SUMS.txt로 파일을 확인하세요. 프리뷰는 안정 버전과 따로 설치됩니다.
  • AI가 만든 칸은 사람이 확인합니다. 인터페이스 ID, 업무명, 인증 여부 "확인 필요"처럼 근거를 못 찾은 칸은 추측하지 않고 비워 둡니다.
  • 비교와 기록은 한 번의 실행을 본 것입니다. 모든 경우에 같게 동작한다는 증명이 아닙니다.

07

막혔을 때

증상해결
실행 모드에 Codex/Claude가 안 보임명령 프롬프트에서 codex --version(또는 claude --version)이 되는지 확인하고, 로그인한 뒤 MonoField를 다시 켭니다.
명세서를 만들 수 없다고 나옴실행 권한이 읽기 전용입니다. 기본으로 바꿉니다.
"현재 작업 폴더는 Git 저장소가 아닙니다"폴더에서 git init, git add -A, git commit -m "baseline"을 실행합니다. 사용자 정보 오류가 나면 git config --global user.name과 user.email을 한 번 설정합니다.
AI가 REA 도구를 못 찾음설정 → 외부 MCP → REA 설치·연결 점검에서 대화에서 AI가 REA 쓰기가 켜져 있는지 보고, 새 대화를 시작합니다. 이미 열린 대화에는 소급되지 않습니다.
REA 점검에서 브라우저를 못 찾음흐름 기록 창의 브라우저 직접 지정에 Chrome·Edge 실행 파일의 전체 경로를 넣습니다.
레퍼런스로 담기 때 화면 캡처가 없음데스크톱 앱에서만 캡처와 구조 요약을 찍습니다. 웹 브라우저로 쓰면 대부분의 외부 사이트가 열리지 않아 주소와 메모만 담깁니다.
버튼에 이름이 없어 흐름 단계로 못 찾음카드의 AI에게 맡기기를 눌러 같은 규칙의 기록 요청을 입력창으로 보냅니다.
한글 필드명이 member Id처럼 나옴용어 사전에 추가하고 다시 만듭니다.

그래도 안 되면 GitHub 이슈에 증상과 화면을 남겨 주세요. 전체 표는 처음 시작하기 6장에 있습니다.

08

명령줄(CLI)

화면에서 되는 일은 명령줄로도 됩니다. 두 쪽이 같은 로컬 데몬의 /api/*를 부르며, 명령마다 --help로 사용법을 볼 수 있고, 대부분 --json 출력을 지원합니다.

명령하는 일
monofield refs …레퍼런스 보드(담기·메모·적용·흐름 기록·비교)
monofield rea status|enable|disable|doctor내장 REA 설정과 점검
monofield rea evidence|cross-check|cite|compareREA 브라우저 기록을 명세서와 대조·인용·원본/재구현 비교
monofield permissions [show|set <level>]실행 권한 확인·변경
monofield verify프로젝트 검사 실행과 결과 기록
