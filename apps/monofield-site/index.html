프리뷰 릴리스 안내 · 체크섬

Windows x64 · 안정 버전과 별도로 설치되는 사전 릴리스입니다. REA는 MCP 설정에서 선택해 첫 사용 시 설치하며 Node·npm과 브라우저가 필요합니다. Laya 모델·서버는 별도 설치하고, Java 도구에는 JDK 21과 적절한 Maven 환경이 필요합니다.

REA × MONOFIELD × LAYA

문서가 부족한 시스템, 근거부터 인수인계하세요.

01 / REA

기존 시스템 조사

선택한 앱의 배포 파일, 화면 동작과 DB를 조사해 출처가 있는 근거를 모읍니다.

02 / MONOFIELD

명세 작성과 검토

에이전트와 함께 확인한 내용과 미확인 사항을 정리하고, 인터페이스 Excel·화면명세 PPTX로 출력합니다.

03 / LAYA · OPTIONAL

애매한 근거 판단 보조

로컬 모델이 근거 일치 여부와 검증 후보 선택을 보조합니다. 결과는 사람이 검토할 제안으로 남깁니다.

실제로 실행해 확인했습니다.

정상·중복·미결제·취소 정산 동작과 저장된 DB 행을 대조했습니다. API 3개의 Excel 명세서와 실제 캡처를 넣은 PPTX 2장을 출력하고 재현 실행까지 확인했습니다.

이 데모는 REA와 MonoField CLI로 수행했으며 Laya는 호출하지 않았습니다. 새 MCP 프리셋과 인수인계 스킬로 지원 로컬 에이전트에 같은 조사 도구를 연결할 수 있습니다.

FAQ

궁금한 점이 있나요?

MonoField는 무료인가요?

데스크톱 앱은 무료이며 Apache-2.0 오픈소스입니다. 연결한 AI 에이전트의 구독료나 모델 API 이용료는 각 제공업체 기준으로 별도 적용됩니다.

어떤 AI를 연결할 수 있나요?

Codex, Claude Code, Gemini, OpenCode 등 지원하는 로컬 에이전트와 직접 설정한 API 엔드포인트를 사용할 수 있습니다. 로컬 에이전트는 설치와 로그인이 필요하고, API 연결은 키·모델·엔드포인트 설정이 필요합니다.

내 파일은 어디에 저장되나요?

프로젝트 파일은 내 컴퓨터에 저장됩니다. AI 작업에 사용하는 입력과 필요한 맥락은 선택한 에이전트나 모델 제공업체로 전달될 수 있습니다.

기존 설치 앱도 업데이트할 수 있나요?

지원되는 설치본은 새 공개 릴리스를 자동으로 확인합니다. 다운로드한 뒤 앱의 안내에 따라 설치 또는 재시작하세요. 소스 코드가 변경됐다는 이유만으로 앱이 자동 교체되지는 않습니다.
