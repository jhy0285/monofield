FAQ

궁금한 점이 있나요?

MonoField는 무료인가요?

데스크톱 앱은 무료이며 Apache-2.0 오픈소스입니다. 연결한 AI 에이전트의 구독료나 모델 API 이용료는 각 제공업체 기준으로 별도 적용됩니다.

어떤 AI를 연결할 수 있나요?

Codex, Claude Code, Gemini, OpenCode 등 지원하는 로컬 에이전트와 직접 설정한 API 엔드포인트를 사용할 수 있습니다. 로컬 에이전트는 설치와 로그인이 필요하고, API 연결은 키·모델·엔드포인트 설정이 필요합니다.

내 파일은 어디에 저장되나요?

프로젝트 파일은 내 컴퓨터에 저장됩니다. AI 작업에 사용하는 입력과 필요한 맥락은 선택한 에이전트나 모델 제공업체로 전달될 수 있습니다.

기존 설치 앱도 업데이트할 수 있나요?

지원되는 설치본은 새 공개 릴리스를 자동으로 확인합니다. 다운로드한 뒤 앱의 안내에 따라 설치 또는 재시작하세요. 소스 코드가 변경됐다는 이유만으로 앱이 자동 교체되지는 않습니다.
