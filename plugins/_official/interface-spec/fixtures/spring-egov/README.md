# eGovFrame-style Spring MVC fixture

Synthetic board module written in the style of Korean public-sector
(전자정부 표준프레임워크) Spring MVC code: `@Controller` handlers mapped to
`.do` URLs, `@RequestMapping` without a `method` attribute, form binding through
`@ModelAttribute` and un-annotated `*VO` parameters, and Korean Javadoc on
handlers and fields. Not copied from any real system.
