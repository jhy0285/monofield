# MonoField 0.11.7-preview.2 — REA + Laya

REA와 Laya 연동을 포함한 MonoField 개발 프리뷰입니다. Windows x64에서 안정 버전과 별도로 설치됩니다.

- **REA**: Settings → External MCP의 REA 프리셋, `monofield rea status|configure|disable --json`, 기존 시스템 인수인계 스킬을 추가했습니다. 배포 JavaScript·브라우저 동작·SQLite 근거를 수집해 검토용 인터페이스 Excel·화면명세 PPTX로 정리할 수 있습니다.
- **Laya**: 로컬 typed-decision 연동, 검증 후보 추천, 온톨로지 근거 선택과 작업 근거 검토를 포함합니다. 판단은 제안이며 실행 증거·승인으로 취급하지 않습니다.
- 이전 개발 브랜치의 편집기 중심 작업 공간, Java 탐색·디버깅, 코드 온톨로지·변경 영향·검증 기능을 함께 반영했습니다.

[REA·Laya 설정 가이드](https://github.com/jhy0285/monofield/blob/main/docs/rea-laya-handover.md) · [실제 합성 샘플 실행 결과](https://github.com/jhy0285/monofield/blob/main/docs/testing/rea-handover-2026-10-22.md) · [검증 범위](https://github.com/jhy0285/monofield/blob/main/docs/testing/rea-laya-release-2026-10-22.md)

REA 프리셋은 첫 사용 시 `rea-agents@6.7.0`을 내려받습니다. SQLite 조사에는 Node 24.15 이상, 브라우저 캡처에는 설치된 Chromium 계열 브라우저가 필요합니다. REA 패키지·분석 엔진 및 Laya 가중치·서버는 자동으로 함께 설치·실행하지 않습니다. Laya의 설치·loopback 설정은 가이드를 따르세요. Java 도구는 JDK 21과 적절한 Maven 환경이 필요합니다.

앱의 외부 MCP 자동 전달은 Claude Code, OpenCode 및 지원 ACP adapter에서 제공됩니다. **Codex는 별도 등록** 후 새 대화를 시작해야 합니다:

```sh
codex mcp add rea -- npx -y rea-agents@6.7.0 --mcp
```

직접 다운로드 설치본은 **서명되지 않았습니다**. `SHA256SUMS.txt`로 다운로드를 확인하세요. 이 릴리스는 preview이며 안정 버전의 latest 다운로드를 바꾸지 않습니다. 전체 개발 UI의 남은 검증·알려진 제한은 보고서에 보존했습니다. 프리뷰 업데이트는 이 페이지의 설치본으로 진행하세요.

합성 샘플의 REA 원본 근거·Excel·PPTX·재현 코드는 [저장소의 실행 번들 ZIP](https://github.com/jhy0285/monofield/blob/main/docs/testing/evidence/rea-handover-2026-10-22/rea-si-handover-20261022.zip)에 포함됩니다. 고객 시스템 검증 결과가 아니며 해당 데모에서는 Laya를 호출하지 않았습니다.
