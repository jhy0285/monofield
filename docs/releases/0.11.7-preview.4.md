# MonoField 0.11.7-preview.4 — 실행 권한

Codex·Claude Code로 SI 산출물까지 끝내는 MonoField 개발 프리뷰입니다. Windows x64에서 안정 버전과 별도로 설치됩니다.

- **설정 → 실행 권한**: Codex와 Claude Code가 이 PC에서 할 수 있는 일을 한 곳에서 고릅니다.
  - **읽기 전용**: Codex는 읽기만 하고 인터넷을 쓰지 않으며, Claude Code는 계획만 세웁니다.
  - **기본**(권장, 지금까지와 같음): 작업 폴더 안에서만 파일을 고치고 명령을 실행합니다.
  - **전체 접근**: Codex는 샌드박스 없이, Claude Code는 모든 도구를 허용한 채 실행하고, Windows에서는 MonoField가 관리자 권한으로 다시 시작합니다. 켜기 전에 확인 창이 뜨고, 켜져 있는 동안 설정 아이콘 옆에 빨간 "전체 접근" 표시가 보입니다.
  - 바꾼 단계는 다음 실행부터 적용됩니다. CLI에서도 `monofield permissions`, `monofield permissions set <read-only|default|full> --json`으로 같은 설정을 다룹니다.
- **관리자 권한 주의**: 전체 접근에서는 MonoField를 켤 때마다 Windows 확인 창(UAC)이 뜹니다. 관리자 권한으로 실행하는 동안에는 탐색기에서 파일을 끌어다 놓을 수 없으며, 파일 선택 버튼은 그대로 쓸 수 있습니다. UAC에서 "아니요"를 누르면 일반 권한으로 계속 실행합니다. **관리자 권한으로 다시 시작하는 흐름은 Windows 실기기에서 아직 확인하지 않았습니다.**
- **작업 공간**: 도구 패널 높이와 파일 미리보기 너비를 조절하고 AI 입력창을 접을 수 있습니다. 새로고침 때문에 중간에 끊긴 문서 작업을 다시 이어 받습니다. Home 상단 로고에 짧은 모션이 들어갔습니다.
- **수정**: 새 프로젝트 패널의 문서 스타일 목록이 창 밖으로 잘리던 문제, 메모리 추가 후 "생성됨" 안내가 바로 사라지던 문제를 고쳤습니다.

직접 다운로드 설치본은 **서명되지 않았습니다**. `SHA256SUMS.txt`로 다운로드를 확인하세요. 이 릴리스는 preview이며 안정 버전의 latest 다운로드를 바꾸지 않습니다. Codex 또는 Claude Code CLI는 별도로 설치·로그인해야 하며, 에이전트가 사용하는 모델 제공업체의 이용 조건과 요금이 그대로 적용됩니다. 프리뷰 업데이트는 이 페이지의 설치본으로 진행하세요.
