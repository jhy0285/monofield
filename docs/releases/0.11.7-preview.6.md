# MonoField 0.11.7-preview.6 — 파일 목록 수정

Codex·Claude Code로 SI 산출물까지 끝내는 MonoField 개발 프리뷰입니다. Windows x64에서 안정 버전과 별도로 설치됩니다. 0.11.7-preview.5의 실행 권한 기능은 그대로이고, 아래 문제를 고쳤습니다.

- **에이전트가 만든 파일이 목록에 바로 보임**: 에이전트, API, 다른 편집기가 프로젝트에 파일을 쓰면 디자인 파일 목록이 곧바로 갱신됩니다. 이전에는 변경 알림을 받고도 1초 동안 저장해 둔 예전 목록을 다시 보여 줘서, 새 파일이 다른 작업으로 목록이 갱신될 때까지 빠져 있을 수 있었습니다.
- **프로젝트를 열 때 미리보기가 다시 로드되지 않음**: 파일 감시가 준비될 때 목록만 다시 맞추고, 열려 있는 미리보기는 그대로 둡니다. 내용이 실제로 바뀐 파일만 미리보기를 새로 불러옵니다.

직접 다운로드 설치본은 **서명되지 않았습니다**. `SHA256SUMS.txt`로 다운로드를 확인하세요. 이 릴리스는 preview이며 안정 버전의 latest 다운로드를 바꾸지 않습니다. Codex 또는 Claude Code CLI는 별도로 설치·로그인해야 하며, 에이전트가 사용하는 모델 제공업체의 이용 조건과 요금이 그대로 적용됩니다. 프리뷰 업데이트는 이 페이지의 설치본으로 진행하세요.
