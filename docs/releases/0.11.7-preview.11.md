# MonoField 0.11.7-preview.11 — Kotlin 코드도 읽습니다

Codex·Claude Code로 SI 산출물까지 끝내는 MonoField 개발 프리뷰입니다. Windows x64에서 안정 버전과 별도로 설치됩니다. 0.11.7-preview.10의 기능은 그대로이고 다음이 바뀌었습니다.

- **Kotlin 읽기**: Spring 컨트롤러를 Kotlin으로 써도 명세서를 만듭니다. `name: Type` 파라미터(`?`나 기본값이 있으면 선택), `data class` 필드(널을 허용하지 않고 기본값도 없으면 필수), `enum class`, KDoc 주석의 한글 이름, `mapOf("key" to value)` 응답, Kotlin 보안 DSL(`authorize("/x", permitAll)`)을 읽습니다. 예제 프로젝트를 Kotlin으로 옮긴 판은 Java판과 같은 명세서가 나오고, 공개된 Kotlin RealWorld 앱에서는 경로 8/8, 요청 필드 20/20, 응답 필드 32/32를 코드와 맞혔습니다. Kotlin 파일을 바꿔도 변경 분석이 코드를 다시 읽어 바뀐 API만 보여 줍니다.
- **메서드 변경을 한 줄로**: `@RequestMapping`을 `@PostMapping`으로 바꾼 것처럼 같은 경로에서 받는 HTTP 메서드만 바뀌면, "API 삭제 + 새 API" 두 줄이 아니라 명세서의 그 API에 "허용 HTTP 메서드 축소"(호환성 깨짐) 또는 "확대"(추가 변경) 한 줄로 보입니다.
- **중복 행 수정**: 응답 DTO 안의 DTO 필드가 두 번 펼쳐져 같은 행이 반복되던 문제를 고쳤습니다.

WebFlux 함수형 라우터와 Ktor, 빌드할 때 생성되는 코드에만 있는 매핑은 읽지 않습니다. [실제 프로젝트 검증](https://github.com/jhy0285/monofield/blob/main/docs/testing/real-projects-2026-11-11.md)

직접 다운로드 설치본은 **서명되지 않았습니다**. `SHA256SUMS.txt`로 다운로드를 확인하세요. 이 릴리스는 preview이며 안정 버전의 latest 다운로드를 바꾸지 않습니다. Codex 또는 Claude Code CLI는 별도로 설치·로그인해야 하며, 에이전트가 사용하는 모델 제공업체의 이용 조건과 요금이 그대로 적용됩니다. 정밀 변경 분석에는 Python 3이 필요합니다. 프리뷰 업데이트는 이 페이지의 설치본으로 진행하세요.
