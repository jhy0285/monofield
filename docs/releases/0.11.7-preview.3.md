# MonoField 0.11.7-preview.3 — SI 산출물 작업대

Codex·Claude Code로 SI 산출물(인터페이스 명세서·화면명세서·인수인계 문서)까지 끝내는 데 초점을 맞춘 MonoField 개발 프리뷰입니다. Windows x64에서 안정 버전과 별도로 설치됩니다.

- **Home**: 인터페이스 명세서·화면명세서·문서·슬라이드를 먼저 보여 주고, 디자인·미디어 템플릿은 "템플릿 더보기" 뒤로 정리했습니다. 온보딩에는 전체 흐름에 로컬 Codex 또는 Claude Code CLI가 필요하다는 안내가 추가됐습니다.
- **인터페이스 명세서 스캐너**: Spring과 전자정부프레임워크(`.do`, `@ModelAttribute`/`*VO`, 한글 Javadoc 이름)를 읽고, Spring Security 설정에서 인증 여부(필요·공개·미정, 근거 포함)를 판단합니다. OpenAPI 3.x와 Swagger 2 명세도 수집합니다.
- **변경 검토**: 명세서 변경을 호환성 깨짐·확인 필요·추가로 분류해 보여 주고, 제안 적용 전 판정을 CLI에서도 확인할 수 있습니다. OpenAPI 3.1 내보내기(`export-openapi`)를 추가했으며, 인증 방식이 확정되지 않은 operation은 공개로 내보내지 않고 `x-auth-undecided`로 표시합니다.
- **DB 근거**: MyBatis XML(여러 줄 SQL 포함)에서 테이블 후보를 찾고, Oracle 계열 스키마 카탈로그 매핑을 추가했습니다(1단계). **Oracle·Tibero 실제 접속은 아직 지원하지 않습니다.**
- **가이드**: 도움말 메뉴와 Home에서 여는 Guide Center(30초 소개 영상, 챕터 이동, 네 단계)를 추가하고 화면 투어를 다듬었습니다.

직접 다운로드 설치본은 **서명되지 않았습니다**. `SHA256SUMS.txt`로 다운로드를 확인하세요. 이 릴리스는 preview이며 안정 버전의 latest 다운로드를 바꾸지 않습니다. Codex 또는 Claude Code CLI는 별도로 설치·로그인해야 하며, 에이전트가 사용하는 모델 제공업체의 이용 조건과 요금이 그대로 적용됩니다. 전체 UI 자동화 스위트 중 일부(설정 저장, Browser Inspiration 등)는 현재 화면과 맞지 않아 아직 갱신하지 못했습니다. 프리뷰 업데이트는 이 페이지의 설치본으로 진행하세요.
