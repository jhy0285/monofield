# MonoField 0.11.7-preview.5 — 실행 권한 보완

Codex·Claude Code로 SI 산출물까지 끝내는 MonoField 개발 프리뷰입니다. Windows x64에서 안정 버전과 별도로 설치됩니다.

- **읽기 전용을 지원하는 에이전트 확대**: Codex와 Claude Code에 더해 Gemini CLI, Qwen Code, CodeBuddy, Copilot도 읽기 전용 단계를 따릅니다(각 CLI의 계획 모드 또는 쓰기·셸 차단 규칙). 읽기 전용 모드가 없는 다른 에이전트는 읽기 전용 단계에서 시작하지 않고 이유를 알려 줍니다. 설정 → 실행 권한에 지원 에이전트 목록이 보입니다.
- **이미지 생성도 실행 권한을 따름**: Codex 이미지 생성은 읽기 전용에서 막히고, 전체 접근에서는 샌드박스 없이 실행됩니다.
- **일반(관리자가 아닌) Windows 계정**: 전체 접근을 골라도 관리자 권한으로 다시 시작하지 않습니다. UAC가 다른 사용자로 앱을 열게 되기 때문입니다. 설정과 `monofield permissions`가 관리자 계정으로 실행하라고 안내합니다.
- **관리자 권한 다시 시작 점검**: 실제 Windows(PowerShell 5.1)에서 관리자 권한 실행 명령이 모든 인자를 그대로 넘기는 것을 자동 테스트로 확인했습니다. 실행 파일이 없을 때는 "UAC 거절"이 아니라 실패로 알립니다. **UAC 확인 창이 뜨는 흐름 자체는 아직 사람이 직접 확인하지 않았습니다.**

직접 다운로드 설치본은 **서명되지 않았습니다**. `SHA256SUMS.txt`로 다운로드를 확인하세요. 이 릴리스는 preview이며 안정 버전의 latest 다운로드를 바꾸지 않습니다. Codex 또는 Claude Code CLI는 별도로 설치·로그인해야 하며, 에이전트가 사용하는 모델 제공업체의 이용 조건과 요금이 그대로 적용됩니다. 프리뷰 업데이트는 이 페이지의 설치본으로 진행하세요.
