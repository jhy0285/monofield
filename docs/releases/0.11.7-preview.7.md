# MonoField 0.11.7-preview.7 — 처음 시작 가이드

Codex·Claude Code로 SI 산출물까지 끝내는 MonoField 개발 프리뷰입니다. Windows x64에서 안정 버전과 별도로 설치됩니다. 0.11.7-preview.6의 기능은 그대로이고, 처음 쓰는 분이 바로 따라 할 수 있도록 안내를 고쳤습니다.

- **처음 시작 가이드 (15분)**: 준비물 확인부터 예제 프로젝트로 첫 인터페이스 명세서를 만들고 코드 변경을 반영하기까지 순서대로 따라 하는 문서입니다. 준비물(Codex 또는 Claude Code CLI, Python 3, Git)마다 확인 명령과 없을 때 할 일을 적었고, 자주 막히는 9가지 증상과 해결 방법을 표로 정리했습니다. [가이드 보기](https://github.com/jhy0285/monofield/blob/main/docs/getting-started.ko.md)
- **예제 프로젝트**: 회원 가입·주문 API가 있는 작은 Spring 프로젝트와 용어 사전을 [ZIP으로 받을 수 있습니다](https://monofield.vercel.app/downloads/monofield-sample-legacy-order.zip).
- **앱 안 가이드**: 도움말(?) → 가이드 · 소개 영상의 네 단계가 실제로 누를 버튼 이름(작업 폴더 선택, 코드베이스에서 생성, Git 변경 분석, AI 제안 검토, OpenAPI 내보내기)을 알려 주고, 처음 시작 가이드로 바로 갑니다.

직접 다운로드 설치본은 **서명되지 않았습니다**. `SHA256SUMS.txt`로 다운로드를 확인하세요. 이 릴리스는 preview이며 안정 버전의 latest 다운로드를 바꾸지 않습니다. Codex 또는 Claude Code CLI는 별도로 설치·로그인해야 하며, 에이전트가 사용하는 모델 제공업체의 이용 조건과 요금이 그대로 적용됩니다. 프리뷰 업데이트는 이 페이지의 설치본으로 진행하세요.
