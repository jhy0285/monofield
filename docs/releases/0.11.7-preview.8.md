# MonoField 0.11.7-preview.8 — 레퍼런스 보드와 REA 내장

Codex·Claude Code로 SI 산출물까지 끝내는 MonoField 개발 프리뷰입니다. Windows x64에서 안정 버전과 별도로 설치됩니다. 0.11.7-preview.7의 기능은 그대로이고 다음이 추가됐습니다.

- **레퍼런스 보드**: 내장 브라우저에서 마음에 든 화면을 **레퍼런스로 담기**(주소, 화면 캡처, 구조 요약, 메모). 카드를 골라 **프로젝트에 넣기**를 누르면 그 화면의 구조·흐름·필드 구성만 이 프로젝트의 코드로 다시 만들어 달라는 부탁문이 입력창에 들어갑니다. 문구·이미지·로고·브랜드 색은 가져오지 않고, 로그인이나 봇 차단은 우회하지 않습니다. [사용법](https://github.com/jhy0285/monofield/blob/main/docs/reference-board.ko.md)
- **REA로 흐름 기록**: 버튼 누르기·입력·기다리기 단계를 적으면 MonoField에 들어 있는 REA가 새 임시 브라우저 프로필로 실행하고, 단계별 결과·호출한 API·마지막 화면을 카드에 붙입니다. 단계로 적기 어려운 흐름은 **AI에게 맡기기**로 넘깁니다.
- **우리 화면과 비교**: 레퍼런스를 적용해 만든 우리 화면을 같은 단계로 기록하고, 단계마다 성공 여부·페이지 이동·서버 요청 종류·화면 요소 종류를 나란히 비교합니다. 다른 단계는 **차이를 입력창에 넣기**로 AI에게 고쳐 달라고 합니다.
- **REA 내장**: REA(`rea-agents` 6.7.0)가 MonoField에 들어 있어 Node.js 설치나 다운로드가 필요 없습니다. **대화에서 AI가 REA 쓰기**가 기본으로 켜져 있어 Codex와 Claude Code가 따로 설정하지 않아도 REA 도구를 받습니다. 설정 → MCP → REA 설치·연결 점검에서 끌 수 있습니다.
- 같은 기능을 CLI로: `monofield refs list|add|note|remove|apply|record|compare`, `monofield rea status|enable|disable`.

직접 다운로드 설치본은 **서명되지 않았습니다**. `SHA256SUMS.txt`로 다운로드를 확인하세요. 이 릴리스는 preview이며 안정 버전의 latest 다운로드를 바꾸지 않습니다. Codex 또는 Claude Code CLI는 별도로 설치·로그인해야 하며, 에이전트가 사용하는 모델 제공업체의 이용 조건과 요금이 그대로 적용됩니다. 흐름 기록에는 설치된 Chrome·Edge·Chromium이 필요합니다. 프리뷰 업데이트는 이 페이지의 설치본으로 진행하세요.
