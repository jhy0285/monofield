Public commands use `monofield`, public environment variables use
`MONOFIELD_*`, extension manifests use `monofield.json`, and packaged Desktop
navigation uses `monofield://`.

Some engineering notes document private workspace package scopes, persisted
data migrations, or read-compatible identifiers from earlier versions. Those
identifiers are implementation details, not supported product entry points.
